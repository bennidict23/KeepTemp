## 本轮修复与回归证据

取消保存前预览、应用二次确认及阅读页重复隐私提示；点一次记录后直接持久化。普通／模式未知在四家与通用来源均走同一主动记录流程。内部角色／身份检查保留，失败直接显示具体错误，不把空白或未完成提取称为成功。

新增真实使用组合：ChatGPT 和通用对话先保存，再关闭自动记录、追加两条消息，再点记录，仍只有一条会话且增至四条。快速两次点击不建立重复副本。搜索框原本无匹配时点击记录，会清空过滤并显示该记录。前端核实 sessionId 对应的已持久化行；没有行或并发删除获胜不能显示成功。

删除后后台捕获仍拒绝回写；用户主动点记录可重新保存当前文字。两个浏览器场景都检查重新落盘、标题非空、刷新后打开正文。事务故障单元验证重新保存失败不撤销 tombstone、不留下写入授权、不自动复活旧内容。

DeepSeek 专门覆盖无 main 的原生虚拟列表、明确用户／助手正文、思考占位到正式回答、多块正文、25 次流式更新、刷新／关页持久化和完整接续复制。另验证用户消息已卸载时，助手正文仍可更新到原记录，原用户文字保留；手动再次记录也不新增副本。

明暗主题测试覆盖 340px 窄面板、中性色计算值、无横向溢出、按钮可访问名称、手动切换、刷新保持和网页标记同步。浅／深色截图均已实际查看。主要记录按钮提升为主操作，平台打开入口为辅助操作；原“⋯”管理、明显返回及直接删除保留。

## 授权测试与生产范围

主要浏览器套件使用隔离的生产构建副本，仅向副本添加两个 synthetic-*.example 与 chat.deepseek.com 的精确测试站点权限，模拟已授权网站；所有请求本地返回合成 HTML。

另一个套件直接使用**未修改的生产 manifest**，不预授予测试 origin。通过 Chrome CDP Extensions.triggerAction 执行原生工具栏 action：之前 URL 不可见，action 后当前页可访问；跨 origin 后临时权限撤回，下一次 action 才恢复。记录点击到达 Chrome 原生权限请求，观察到仅请求当前 origin，应用没有额外预览／确认界面；原生弹窗仍等待时没有记录或 Saved。测试不替换 Chrome 的权限决定，也不冒充原生授权已经获准。允许／拒绝及页面变化在控制器单元和精确预授权的浏览器闭环覆盖。

生产默认 host 与声明式脚本仍只有四家；全 HTTPS 仅作为 optional 申请范围。权限未增加 tabs、请求拦截或凭据能力。

## 验证边界

全部自动化内容为合成数据，不访问用户私人 Chrome profile、真实账号或私人聊天；测试／诊断入口未进入产品。没有将真实内容放入日志或截图。

早期 ChatGPT 识别保存曾由用户确认可用。本轮新交互及 Claude／Grok／Gemini／DeepSeek／通用规则未穷尽真实账号灰度、语言和地区布局，不能用合成通过宣称全部兼容。

未实际填满磁盘、模拟断电、验证取证级擦除或完整浏览器重启后的全部 tab 身份变化。写入失败使用合成 QuotaExceededError。没有调用真实模型评价接续质量；格式／剪贴板一致性不保证模型行为一致。扩展更新后旧内容脚本的全部 Chrome 生命周期仍非完整覆盖，缺脚本补加载已有独立回归。
