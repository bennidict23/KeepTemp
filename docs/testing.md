## 验证边界

所有自动化均为合成内容，支持站点请求被本地路由替代，不访问真实账号，不读取私人 Chrome profile。测试和截图只有合成文字，产品不包含测试页或诊断收集。

ChatGPT 的 0.2.2 识别和保存曾由用户确认可用。本版通用保存、DeepSeek 和 Claude／Grok／Gemini 捕获尚未经过真实账号验收；公开 DOM 资料和合成页面无法证明当前每个灰度、账号、语言兼容。新增三家保持实验标记。

通用集成测试复制生产扩展到独立临时目录，仅在测试副本的 host_permissions 增加两个 synthetic-*.example 与 chat.deepseek.com，模拟用户已授予的精确站点权限，所有请求均返回合成 HTML。默认安装的四站点范围、全 HTTPS 仅为 optional、generic 不声明式注入，由原生产 manifest 单独断言。Chrome 原生站点授权弹窗、工具栏 activeTab 点击授权没有在 headless 中自动验证，拒绝授权／活动页变化在控制器单元测试覆盖，真实弹窗须用户验收。没有读取个人 Chrome 配置或通过源码扩大生产默认权限。

没有调用真实模型评价接续效果。角色／剪贴板测试不是目标模型完整接收、行为一致或回复质量保证。

尚未覆盖完整浏览器重启、真实扩展更新的全部生命周期、断电、磁盘耗尽、SSD 擦除、附件／工具／原服务器状态恢复。写入失败使用注入的合成 QuotaExceededError，没有填满用户磁盘。CI 仅有示例，未宣称远端通过。

## 下一轮手动验收

1. 保留原安装目录，在 chrome://extensions 刷新扩展并重新打开侧边栏；确认旧记录仍在，新增平台尚未自动启用。
2. 每家分别手动开启临时／隐身／私密模式，只聊合成测试内容；点“记录当前对话”。确认 Saved、角色／正文、继续流式回复、关页再读、普通聊天拒绝保存。
3. 把一段 ChatGPT 合成记录复制到 Claude 或 Gemini 新临时会话，粘贴发送，观察能否承接目标与未完成请求。接续是恢复文字背景，不是原服务器状态。
4. 测试 SPA 新会话、刷新和双标签，不应串记录；若拒绝识别只报告平台、模式与保存状态，不发送私人内容。

5. 在 DeepSeek 或另一 HTTPS 聊天网页从工具栏打开 KeepTemp，点“记录当前对话”。先核对预览中的角色和全文，确认 Chrome 只申请当前网站访问，点确认后核对 Saved、增量更新和关页读取。确认前不应在列表出现记录；这是普通／未知模式的主动副本，网站历史可能仍存在。
6. 切换会话必须重新确认；更换 tab 或 SPA 路由后旧预览不能保存。刷新同一已确认会话应恢复；若网站原生身份不足，报告显示的原因即可，不发送私人聊天内容。
