# KeepTemp QA 场景清单

版本 0.6.0。使用隔离 Chromium 和合成数据模拟用户，不读取个人 Chrome profile 或私人聊天。结果及未覆盖范围见 [测试记录](testing.md)。

| 使用场景 | 验收结果 | 自动验证 |
| --- | --- | --- |
| 未同意本地保存就打开聊天 | 不保存 | 单元＋浏览器 |
| 已有临时聊天中途打开扩展 | 不刷新网页，一次记录已有文字，继续增量保存 | 单元＋浏览器 |
| 普通／模式未知点击记录 | 一次点击保存，无应用预览／二次确认 | 四家＋通用浏览器场景 |
| 首次访问新网站 | 只请求当前 origin，等待授权期间无 Saved／记录 | 原生产 manifest 的 Chrome 原生动作＋请求验证 |
| 拒绝权限／活动页面改变 | 不提交或报成功 | 控制器单元 |
| 一段回复持续流式输出 | 更新同一消息，不拆成多条 | 50 次单元更新、25–30 次浏览器更新 |
| 关自动记录后新增两轮，再点记录 | 原会话更新到四条，仍只有一个副本 | ChatGPT＋通用浏览器 |
| 快速重复点击 | 不并行弹权限／建重复副本，内容保持完整 | 浏览器 |
| 搜索无结果时记录当前页 | 清掉旧过滤，保存的会话可见 | 浏览器 |
| 删除后页面仍继续生成 | 不自动恢复本地副本 | 单元＋浏览器 |
| 删除后主动再次点击记录 | 真正重新落盘，刷新后能打开，标题和文字非空 | ChatGPT＋通用浏览器 |
| 删除后重新保存遇到写入故障 | 不留下授权、不撤销删除、不虚报 Saved | 事务故障单元 |
| DeepSeek 用户消息被虚拟列表卸载 | 助手继续更新，已存用户消息保留 | 单元＋浏览器 |
| 暂停后点击记录 | 不绕过暂停；恢复后保存当前文字 | 单元＋浏览器 |
| SPA 切到另一通用会话 | 自动记录停止，新会话需点记录 | 浏览器 |
| 同站多标签／跨站相同原生 ID | 独立会话，不串内容 | 单元＋浏览器 |
| 看到 Saved 后刷新或关页 | 记录仍能从会话库打开 | 浏览器 |
| 注入存储失败再恢复 | 先显示失败，恢复后可重试，授权与正文原子提交 | 单元＋浏览器 |
| 没有 main 的 DeepSeek 虚拟列表 | 从原生区域识别角色和完整正文 | 单元＋浏览器 |
| 只有思考、没有任何正文 | 不把空内容称为已保存对话 | 单元 |
| 侧栏／弹窗／重复区／冲突角色 | 不混入正文，无法确定则拒绝 | 单元＋浏览器失败场景 |
| 重命名后继续生成或刷新 | 名称保留，正文更新，取消删除不影响数据 | 单元＋浏览器 |
| 复制接续与导出 | 角色和完整存储文字一致，无平台名附加、无自动发送 | 单元＋实际剪贴板／下载验证 |
| 清空所有记录 | 正文、标记、保存授权清空，活跃页不回写 | 单元＋浏览器 |
| 340px 侧栏、长文、滚到底部 | 无横向溢出；返回与删除可见可点 | 浏览器＋截图检查 |
| 明暗切换、刷新、系统颜色改变 | 黑／白配色、选择持久化、网页标记同步 | 浏览器＋浅深色截图人工核对 |

原生 Chrome 权限弹窗在 headless 中验证到等待阶段，不自动宣称“用户点击允许”已经测试。允许／拒绝逻辑由控制器单元和精确预授权的隔离站点测试覆盖。测试不模拟真实磁盘耗尽或断电；QuotaExceededError 为合成注入。

公开工程资料和合成 DOM 不是平台稳定接口。真实账号、语言、地区与灰度布局的全部组合仍不能据此宣布兼容；目前没有使用真实账号调用模型评价接续回复质量。
