- 63 项单元测试通过（4 个测试文件）。覆盖持久化、双重授权、50 次流式更新、旧更新保护、会话隔离、暂停／排除、删除防回写、并发清空撤权、全文搜索、虚拟化顺序、消息桥大小及角色校验、重命名不被后续捕获覆盖。

- 14 项浏览器集成测试通过（39.4 秒）。实际加载构建产物，覆盖剪贴板／导出／搜索、流式回复去重、虚拟化／SPA／刷新／多标签／关页持久化、暂停恢复、普通聊天拒绝、后台注入写入失败及重试、删除清空后不回写、窄面板浅深色、权限精确范围。
- 三家合成站点使用对应真实 origin 的本地请求路由，验证内容脚本和后台完整链路、来源显示、流式多段正文、刷新不重复和关页后读取。四个平台同时打开不混淆；ChatGPT → Claude／Gemini 的目标选择只改变链接，复制原文和平台中立提示词，不自动打开／粘贴／发送。
- 中途接管：已有两轮 ChatGPT 消息一次保存四条，后续第三轮自动记录；重复不新建浮层或会话，URL 和 DOM 不刷新。用 WXT 生命周期信号模拟接收器缺失，实际通过 scripting 补加载。Claude 当前会话接管只开启 Claude，不开启另一个 Gemini 标签页。
- UI 回归：阅读页直接删除、长对话滚动后“返回”仍可点、列表“⋯”重命名／删除、Escape 还原焦点、取消确认不删除、窄面板无横向溢出。已查看合成截图。

## 验证边界

所有自动化均为合成内容，支持站点请求被本地路由替代，不访问真实账号，不读取私人 Chrome profile。测试和截图只有合成文字，产品不包含测试页或诊断收集。

ChatGPT 的 0.2.2 识别和保存曾由用户确认可用。本版跨平台入口及 Claude／Grok／Gemini 捕获尚未经过真实账号验收；公开 DOM 资料和合成页面无法证明当前每个灰度、账号、语言兼容。新增三家保持实验标记。

没有调用真实模型评价接续效果。角色／剪贴板测试不是目标模型完整接收、行为一致或回复质量保证。

尚未覆盖完整浏览器重启、真实扩展更新的全部生命周期、断电、磁盘耗尽、SSD 擦除、附件／工具／原服务器状态恢复。写入失败使用注入的合成 QuotaExceededError，没有填满用户磁盘。CI 仅有示例，未宣称远端通过。

## 下一轮手动验收

1. 保留原安装目录，在 chrome://extensions 刷新扩展并重新打开侧边栏；确认旧记录仍在，新增平台尚未自动启用。
2. 每家分别手动开启临时／隐身／私密模式，只聊合成测试内容；点“记录当前临时会话”。确认 Saved、角色／正文、继续流式回复、关页再读、普通聊天拒绝保存。
3. 把一段 ChatGPT 合成记录复制到 Claude 或 Gemini 新临时会话，粘贴发送，观察能否承接目标与未完成请求。接续是恢复文字背景，不是原服务器状态。
4. 测试 SPA 新会话、刷新和双标签，不应串记录；若拒绝识别只报告平台、模式与保存状态，不发送私人内容。
