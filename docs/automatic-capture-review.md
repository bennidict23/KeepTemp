## 当前决策

**核心产品尚未可行性通过。** 没有找到已确认获准、同时符合原项目约束的真实来源。保留可运行的工程原型，暂停手动流程、分类、搜索等功能扩展。合成测试通过仅证明本地捕获/存储/恢复机制可工作，不能证明 ChatGPT DOM 稳定性、平台许可或产品可用性。

## 允许继续开发真实适配器的门槛

1. 取得适用此用途的可核验许可或清晰的官方允许说明，记录范围、日期、适用条件和公开分发限制；不把沉默视为同意。
2. 只在用户明确指定的合成测试账号／合成聊天上验证 DOM。不访问用户现有私人聊天。
3. 证明 Temporary 身份能严格识别、消息 id 稳定、流式更新与导航/刷新隔离可靠；不确定即停止捕获。
4. 定义最小 host 权限，重新取得对应授权；先加专门的真实适配器回归用例，再考虑发布。

如果许可最终不能取得，原目标在现有约束下应停止。是否改做独立聊天客户端、企业工具或其他平台，需要用户另外改变产品范围；本次不把这些方向偷偷替代原需求。
