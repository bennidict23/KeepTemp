# 验证记录

版本：0.3.5。日期：2026-11-02。环境：macOS Apple Silicon、Node.js 22、Playwright Chromium 独立临时 profile。

## 当前结果

- TypeScript 类型检查、生产构建与打包通过，ZIP 约 89.14 KB。
- 40 项单元测试通过：持久化、双重授权、50 次流式更新去重、旧更新保护、会话隔离、暂停/排除、删除防回写、并发清空撤权、全文搜索、虚拟化顺序、新旧页面结构与消息桥校验，以及重命名保留原消息/最后活动时间、随后捕获不覆盖标题、删除后不能重命名复活。
- 恢复用例检查完整原文字和角色、固定接续提示词、无冲突的历史边界、未截断长上下文，以及不附带提示词的 Markdown/JSON 导出。
- 9 项浏览器集成测试通过（23.7 秒），覆盖实际剪贴板内容与导出、搜索、虚拟化/SPA/刷新/多标签/关闭页面后读取、折叠控制、暂停恢复、普通聊天拒绝、后台写入失败及重试、删除和清空后活跃页面不回写、窄面板浅色/深色及权限范围。
- UI 回归包括：长对话滚到底部后“返回”仍位于视口且可点回列表；阅读页无需展开管理菜单即可删除；列表“⋯”可直接重命名/删除；Escape 关闭菜单并恢复焦点；重命名在刷新及后续捕获后保留；删除确认取消不删数据、确认才删除。

已查看合成内容生成的窄面板对话库、阅读页、深色阅读页及菜单截图；无横向溢出。网页状态标记默认高度小于 65px。

新增中途接管用例：独立打开聊天后先有两轮消息，再点“记录当前临时会话”，一次持久化四条，自动记录后续第三轮；重复点击不重复建会话或注入浮层；URL 与 DOM 标记保持未刷新。另通过 WXT 生命周期信号使原内容脚本失效，实际触发 scripting 补加载并保存现有文字。此用例验证接收器缺失的补加载，不等于完整验证 Chrome 卸载/更新扩展的全部生命周期。

单元测试还覆盖来源限制、未授权、普通/未知临时模式、站点权限拒绝、忙碌重试、暂停/排除、首轮保存与开启自动记录的事务一致性，以及写入故障不留下开启状态。未使用私人账号或真实聊天。

## 验证边界

自动化测试只用合成内容，chatgpt.com 请求由本地路由返回合成 HTML，不读取真实平台或用户私人 Chrome profile。开发测试不会打包进扩展，产品没有模拟页或诊断入口。

用户已确认 0.2.2 的真实页面识别和保存可用。后续为界面与接续体验迭代，真实账号本版交互尚待用户体验。没有自动调用真实模型评估接续效果；格式和剪贴板测试不是模型回复质量保证。

尚未覆盖全部灰度/语言界面、完整浏览器重启、断电、真实磁盘耗尽、SSD 擦除、附件/工具或原服务器状态恢复。写入失败测试注入合成 QuotaExceededError，没有填满用户磁盘。尚无远端 CI 通过结论，保留工作流示例供日后启用。
